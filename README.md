# LINE AIコーディネート提案アプリ

LINE上でユーザーの希望条件や服の画像をもとに、AIがコーディネートを提案するアプリです。

## 📌 概要

ユーザーがLINE上で

* 性別
* ファッション系統
* 年齢
* 色
* 季節
* 予算
* 着ていく場所

などの条件を入力すると、AIが条件に合わせたコーディネートを提案します。

また、服の画像を送信することで、画像を解析してコーディネートを提案することもできます。

提案されたコーディネートは画像として生成され、トップス・ボトムス・靴をAmazonで検索できるリンクも表示します。

---

## ✨ 主な機能

### 1. テキストからコーディネートを提案

LINE上で質問に回答していくことで、希望するコーディネートの条件を設定できます。

```text
性別
 ↓
ファッション系統
 ↓
年齢
 ↓
色
 ↓
季節
 ↓
予算
 ↓
着ていく場所
 ↓
AIによるコーディネート提案
```

入力した条件はDynamoDBに保存されます。

### 2. 画像からコーディネートを提案

LINEから服の画像を送信すると、画像を解析してコーディネートを提案します。

```text
服の画像
 ↓
Amazon Rekognition
 ↓
画像からラベルを検出
 ↓
Gemini API
 ↓
コーディネートを提案
 ↓
Imagen
 ↓
コーディネート画像を生成
```

画像解析ではAmazon Rekognitionを使用し、検出したラベルをGemini APIに渡しています。

### 3. AIによるコーディネート画像生成

Geminiが提案した

* トップス
* ボトムス
* 靴

の情報をもとにImagenでコーディネート画像を生成します。

生成した画像はAmazon S3に保存し、署名付きURLを発行してLINEから表示できるようにしています。

### 4. 商品検索

コーディネートの提案結果から、以下の商品をAmazonで検索できます。

* トップス
* ボトムス
* 靴

AIが生成した検索キーワードをAmazon検索URLに変換して、LINEのボタンからアクセスできるようにしています。

### 5. 入力履歴の確認

「履歴」「会話履歴」「ログ」と入力すると、DynamoDBに保存されているユーザーの入力内容を確認できます。

```text
・性別
・カテゴリー
・年齢
・色
・季節
・予算
・住所
```

## 💡 技術選定理由

### LINE Messaging API

普段から利用されているLINE上でアプリを利用できるようにするため採用しました。

また、Quick ReplyやFlex Messageを利用することで、ユーザーが選択しやすいUIをLINE上で実装しました。

### AWS Lambda

LINEから送信されたWebhookを受け取り、AIによる処理を実行するバックエンドとして利用しています。

LambdaのエントリーポイントからLINEのWebhookイベントを処理する構成にしています。

### Amazon DynamoDB

ユーザーごとに入力した条件を保存し、後から履歴を確認できるようにするため採用しました。

ユーザーIDをキーとして、性別やカテゴリー、年齢などの情報を保存しています。

### Amazon Rekognition

ユーザーが送信した服の画像から、画像に含まれる物体や特徴を検出するために使用しています。

検出したラベルをGemini APIに渡すことで、画像をもとにしたコーディネート提案につなげています。

### Google Gemini API

ユーザーが入力した条件や画像解析結果をもとに、トップス・ボトムス・靴などの具体的なコーディネートを生成するために使用しています。

### Google Imagen

Geminiが生成したコーディネート内容をもとに、実際のコーディネートイメージを生成するために使用しています。
