# LINE服装提案AIチャットボット

## 概要
ユーザーの年齢・性別・季節・予算などの条件をもとに、
AIが服装を提案し、関連する商品を検索できるLINEアプリ。

## 主な機能
- ユーザー情報の入力
- AIによる服装提案
- 服の画像認識
- 商品検索
- LINE上での選択式操作

## 使用技術
- Python
- LINE Messaging API
- AWS Lambda
- Amazon DynamoDB
- Amazon S3
- Amazon Rekognition
- Google Gemini API
